# Easy GitHub upload steps

1. Add your final generated figures to `Figures/`.
2. Add your final non-identifiable CSV result tables to `Results/`.
3. Go to GitHub and create a new public repository.
4. Open the new repository and choose **Add file → Upload files**.
5. Drag the contents of this folder into the upload area.
6. Enter the commit message:
   `Upload complete UCEC workflow Scripts 01-20`
7. Select **Commit changes**.
8. Copy the repository address and add it to the thesis under Code availability.

You do not need to upload the HTML or PDF for the code-availability requirement.
They are optional supplementary outputs.
