# UCEC molecular subtype classification

**Student ID:** 3070204

This repository contains the complete R workflow used for the UCEC molecular
subtype classification project.

## Included code

- Scripts 01–15: primary data analysis
- Scripts 16–20: final figures and tables
- Low-memory master R Markdown
- Final reproducibility-report R Markdown

## Repository structure


## Data

Raw TCGA and CPTAC data are not included. The scripts expect the data to be
placed in the same project-relative folders used during the analysis.

## Reproducibility

The repository shares computational code and selected non-identifiable
scientific outputs. Raw source data should only be redistributed where the
relevant access and reuse terms permit it.
